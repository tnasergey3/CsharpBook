# Введення у програмування та встановлення середовища розробки.

[◀️ До змісту лабораторних](README.md)

---
*Мета роботи:* розглянути: платформу Microsoft .NET, особливості налаштування середовища розробки, особливості компіляції та запуску проектів, структуру програми та обробку синтактичних помилок мови програмування С#.

*Обладнання, технічне забезпечення:* персональний комп’ютер, або ноутбук; програмне забезпечення: Visual Studio Code або Visual Studio Community.



**Порядок виконання роботи**
1. Ознайомитися з теоретичними відомостями та виконати поставлені задання:
2. Встановити середовище розробки Visual Studio Community або Visual Studio Code.
3. Створити першу консольну програму на C# в якій вивести в консоль свою групу та ПІБ.
4. Відповісти на контрольні запитання та оформити звіт до лабораторної роботи.



**Контрольні питання**
1. Що таке комп’ютерна програма.
2. Розкрийте особливості двійкової системи числення.
3. Навіщо потрібен компілятор.
4. Що таке середовище розробки. Опишіть відомі вам середовища розробки для мови програмування С#.
5. Розкрийте історію виникнення мови програмування С#.
6. Що являю собою платформа Microsoft .NET.
7. Поясність, що виконує даний код Console.WriteLine().
8. Яка структура програми на мові програмування С#.
9. Які особливості синтактичних помилок.
