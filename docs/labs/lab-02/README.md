*Обладнання, технічне забезпечення:* персональний комп’ютер, або ноутбук; програмне забезпечення: Visual Studio Code або Visual Studio Community.

## Порядок виконання роботи
1. Ознайомитися з теоретичними відомостями (розділ 2).
2. Створити програму, яка б виводила на консоль розміри усіх числових типів да їх граничні значення.
3. Створити програму, яка б обробляла введення строки та числа із консолі, а потім виводила б їх на консоль.
4. Виконати безкоштовне практичне завдання від Microsoft за посиланням: https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/tutorials/hello-world. 5. Скриншот кожного виконаного завдання слід додати до звіту.
6. Результат виконання додати до звіту у вигляді скріншотів. Відповісти на контрольні запитання відповіді додати до звіту.

## Контрольні питання
1. Які основні типи даних є в C#
2. Що робить код Console.ReadLine()
3. Що таке літерали
4. Що таке приведення типів
5. Що таке рядкові літерали та навести приклад
6. Що таке логічні типи даних
7. Що таке область дії змінної
8. Що таке не явно типізовані зміні навести приклад
9. Навести приклад керуючих послідовностей символів
10. Як відбувається зчитування чисел з консолі навести код в якості прикладу
