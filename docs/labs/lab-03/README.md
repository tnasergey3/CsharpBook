*Обладнання, технічне забезпечення:* персональний комп’ютер, або ноутбук; програмне забезпечення: Visual Studio Code або Visual Studio Community.

## Порядок виконання роботи
1. Ознайомитися з теоретичними відомостями (розділ 3).
2. Створити програму, яка б видавала результат виконання усіх арифметичних операцій для введених пари чисел.
3. Створити програму калькулятор із консольним інтерфейсом, спершу ввести тип операцій можна використовувати як символи так і числа, а потім два числа після чого вивести результат на консоль.
4. Виконати безкоштовне практичне завдання від Microsoft за посиланням: https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/tutorials/numbers-in-csharp. Скріншот кожного виконаного завдання слід додати до звіту.
5. Результат виконання додати до звіту у вигляді скріншотів. Відповісти на контрольні запитання відповіді додати до звіту.

Приклад програми, яка сумує два введених числа.
Лістинг 7.3.1

```csharp
Console.WriteLine("Введіть перше число");
int arg1 = int.Parse(Console.ReadLine());
Console.WriteLine("Введіть друге число");
int arg2 = int.Parse(Console.ReadLine());
int sum = arg1 + arg2;
Console.WriteLine($"Результат суми введених чисел: {sum}");
```

## Контрольні питання
1. Розкрити поняття оператор в мові С#
2. Перелічити усі арифметичні оператори.
3. Що таке оператор присвоєння.
4. Для чого використовуються оператор?
5. Перерахувати оператори в порядку пріоритету.
6. Навести приклади скорочених логічних операторів.
7. Перелічити усі логічні оператори.
