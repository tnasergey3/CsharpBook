## Порядок виконання роботи
1. Ознайомитися із теоретичними відомостями (розділ 5).
2. Виконати практичне завдання за посиланням: https://learn.microsoft.com/en-us/training/modules/csharp-for/. Скріншот кожного виконаного завдання слід додати до звіту.
3. Виконати практичне завдання за посиланням: https://learn.microsoft.com/en-us/training/modules/csharp-do-while/. Скріншот кожного виконаного завдання слід додати до звіту.
4. Вивести на екран усі числа від нуля до введеного користувачем числа.
5. Користувач вводить дві межі діапазону, вивести на екран усі числа з цього діапазону. Передбачити, щоб користувач міг вводити межі діапазону у довільному порядку.
- вивести всі парні числа з діапазону.
- вивести всі непарні числа з діапазону.
- вивести всі числа, кратні семи.
6. Користувач вводить дві межі діапазону. Порахувати суму всіх чисел діапазону.
7. Користувач із клавіатури вводить числа. Розрахувати їх суму і вивести на екран, як тільки користувач введе нуль.
8. Написати програму, яка виводить на екран таблицю множення на k де k – номер варіанта. Наприклад, для 9-го варіанта:

9 x 2 = 18;
9 x 3 = 27.

9. Відповідно до вимог оформити звіт до лабораторної роботи.

Приклад програми де використовується цикл щоб не завершувати програму після виконання однієї команди.

Лістинг 7.5.1
```csharp
bool isExit = false;
while (!isExit)
{
Console.WriteLine("Список команд");
Console.WriteLine("1 - вивести число яке ввели");
Console.WriteLine("2 - вивести випадкове число");
Console.WriteLine("3 - вивести строку на екран");
Console.WriteLine("0 - для завершення програми");
int command = int.Parse(Console.ReadLine());

if (command == 1) {
  Console.WriteLine("Введіть число");
  int arg = int.Parse(Console.ReadLine());
  Console.WriteLine($"Ви ввели : {arg}");
}
else if (command == 2) {
  Random rnd = new Random();
  int randomNumber = rnd.Next(1, 100);
  Console.WriteLine($"Випадкове число : {randomNumber}");
}
else if (command == 3) 
  Console.WriteLine("Hello world");
else if (command == 0)
  isExit = true;
else
  Console.WriteLine("Невідома команда використовуйте число від 1 - 3");
}
```

## Контрольні питання
1. Описати оператор while. Приклад використання.
2. Описати оператор do ... while. Приклад використання.
3. Описати оператор for. Приклад використання.
4. Описати оператор foreach. Приклад використання.
5. Застосування оператора break. Приклад використання.
6. Застосування оператора continue. Приклад використання.
